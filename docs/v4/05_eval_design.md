# v4 評估設計：情境、資料集與指標

更新：2026/10/18

## 1. 使用者情境

依論壇調查（02_market_research.md，PTT 149 則標題手動編碼、政大 Dcard 志願序串 27 篇），學生向選課助理提的需求可以歸成下表。比例是多標籤估計，誤差約正負 5 個百分點。

| 情境 | 例句 | 估計比例 | 系統要做的事 | 能回答的資料 |
|---|---|---|---|---|
| 主題找課 | 想學怎麼做市場調查 | 30% | 語意檢索 | 課程目標、大綱、週次主題 |
| 負擔與給分 | 有沒有涼一點的通識、這門甜嗎 | 25%、20% | 依評價排序或回答 | 歷屆評鑑、評分方式、授課方式比例 |
| 老師口碑 | {老師}的課雷不雷 | 20% | 指名查詢後彙整評價 | 歷屆評鑑 |
| 時段 | 週三下午、不要早八 | 15% | 硬條件過濾 | 時間代碼 |
| 學分與通識類別 | 還缺社會通識 | 15% | 硬條件過濾 | kind、lmtKind、學分 |
| 選不選得上 | 排第幾比較有機會 | 15% | 選課結果 | RESULT、志願序回報 |
| 修課資格 | 外院大二能修嗎 | 10% | 依成績單判斷 | 備註、開課班級、成績單 |

查詢平均很短：論壇問句庫中位數 16 字。Kucia and Gawlik (2026) 在大學院系資訊系統上量到真實查詢平均 6.8 字、合成查詢 15.7 字，並發現在合成查詢上調好的設定遇到真實查詢會掉分。v1、v3 的評估全部是 LLM 讀課程內容生成的長句，這是 v4 加入真實口吻子集的原因。

## 2. 資料集

| 子集 | 題數 | 來源 | 標準答案 | 用途 |
|---|---|---|---|---|
| R | 248 | 論壇調查整理的問句，佔位符用 114-2 有評鑑的真實老師與課填入 | gpt-oss:120b 參考拆解（主題、硬條件、指名、偏好、意圖）；指名題有明確目標課；主題相關度由 judge 評分 | 主要的端到端評估 |
| T、M、C | 240、200、300 | v3（eval_synth 與 eval_conditions_v1） | v3 qrels 加資料庫判定 | 和 v1、v3 數字銜接 |
| parse | 220（有效 185） | eval_conditions_v1 分層抽樣 100、eval_synth 120 | 執行結果比對 | 比較小模型解析能力 |
| tool | 30 | 手寫情境 | 預期工具與參數 | 比較小模型工具呼叫 |
| eligibility | 180 | 備註含限制的 60 門課 × 3 個學生設定 | gpt-oss:120b 判定 yes／no／unsure | 比較規則與 LLM 判斷修課資格 |

參考模型選 gpt-oss:120b 的理由：系統本身只用 Gemma 與 Qwen，評審和標註換成第三個模型家族，降低自我偏好（Clarke and Dietz, 2024）。Ollama Cloud 免費方案只開放 gemma4:31b 與 gpt-oss:120b 兩個雲端模型，DeepSeek、GLM、Kimi 都需要付費。

主題相關度的評審沿用 v3 的 qwen3:14b 與 UMBRELA (Upadhyay et al., 2024) 的 0–3 分提示，評審只看課程原始欄位，不看 LLM 生成的摘要。人工校準頁已經做好（100 對），κ 待標註後計算。

## 3. 指標

每個指標都寫明命中的定義。

| 指標 | 命中定義 | 量什麼 |
|---|---|---|
| nDCG@10 | 分數 = 主題分（0–3）× 是否滿足全部硬條件；指名題分數 = 是否為指名的那門課 | 排序品質 |
| Success@10 | 前 10 名至少一門分數 ≥ 2 | 有沒有至少一門能用的課 |
| Precision@10 | 命中 = 滿足全部硬條件（資料庫判定） | 條件有沒有被遵守 |
| MRR@10 | 命中 = 指名的課（同名同師的所有班） | 指名查詢找不找得到 |
| PrefAlign@5 | 前 5 名的面向分數與偏好方向的一致程度，範圍 −1 到 1 | 涼、甜、不分組這類偏好有沒有被反映 |
| 延遲 | 每個階段的中位數與 p95 | 能不能在低階硬體上跑 |

解析與工具呼叫另外評：

- 解析：把解析出的條件丟進資料庫，看正解課是否被保留（gold kept），以及篩出的課和標準答案的 Jaccard。字串比對的 slot F1 會因為系所欄位是班級字串而失真，不採用。
- 工具呼叫：工具選對的比例、參數正確比例、出現禁止參數的比例（例如想學日文卻設授課語言為日文）。
- 修課資格：和參考答案一致的比例、應擋的有沒有擋到（no recall）、不該擋的被擋掉的比例（false block）。

## 4. 已知限制

- 主題相關度靠 LLM 評審，絕對分數偏寬。系統之間的相對差比絕對值可信。
- R 子集的問句由 agent 從論壇整理改寫，不是學生本人打的字。
- 偏好的正確答案來自評鑑面向抽取，抽取本身也是 LLM 做的；另用 gpt-oss:120b 對 60 門課抽一次，比較兩者一致性。
- 2026/10/18 發現 kind 代碼對應錯誤（3 是群修、4 是通識，體育課是 kind 1），eval_conditions_v1 中含課別條件的題目答案是錯的，已排除。v3 中與課別有關的分數需要重算。
